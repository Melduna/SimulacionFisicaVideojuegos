# Manual de juego
Este es el manual de uso para *Starware*, un juego del género *rail shooter* inspirado por títulos como *Star Fox*, y tomando elementos de *microgames* como aquellos destacados en *WarioWare*.

## Controles
El juego presenta un espacio tridimensional en el que el jugador pilota una nave a través de dos ejes mediante las teclas 'I','J','K','L' y disparar en el tercero mediante la tecla 'Z'. Este deberá enfrentarse a varias oleadas de naves enemigas, con el objetivo de derribarlas lo más rápido posible mediante el uso de estas herramientas. El botón de disparo (tecla 'Z') también permitirá al jugador navegar a través de los distintos menús del juego, lo que se indicará mediante la interfaz.
## Objetivo
En cada nivel, el jugador debe derribar una serie de naves enemigas en un patrón aleatorio de una colección predefinida bajo un límite de tiempo que disminuye en cada ronda. De cumplir este objetivo exitosamente, el jugador avanzará a la siguiente ronda; de lo contrario, perderá una vida. El jugador posee 3 vidas, y si caen bajo 0, este perderá la partida. El juego continuará indefinidamente hasta que el jugador pierda la partida o lo cierre manualmente. Antes de cada ronda, el jugador dispondrá de tres segundos durante los que prepararse para la siguiente oleada.
<br>El objetivo final del juego es adquirir la mayor puntuación posible, completando el mayor número de rondas sin perder todas las vidas a medida que el límite de tiempo disminuye.
